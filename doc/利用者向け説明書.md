# クリスマスツリー 利用者向け説明書

## はじめかた

アプリを開くと、画面中央に3Dのクリスマスツリーが表示されます。画面左上のボタンで飾りを選び、ツリーの葉をクリックして飾りを置きます。画面右側には、操作結果のメッセージが必要なときだけ表示されます。

## 飾りを置く

1. 画面左上で置きたい飾りを選びます。
2. ツリーの葉の置きたい位置をクリックします。
3. 続けて置く場合は飾りを選び直す必要はありません。別の種類を選ぶと、選択中の飾りが切り替わります。

選べる飾りは、ボール、星、雪の結晶、プレゼント、キャンディケイン、リース、ベル、靴下です。マウスホイールでも種類を切り替えられます。ボタンの並びの順番で、ホイールを下ろすと次の種類、上げると前の種類になります。クリックした位置の近くに空きがない場合や上限に達した場合は、画面右側にメッセージが表示されます。

- 飾りは合計50個まで置けます。
- 同じ種類は20個まで置けます。
- Deleteキーを1回押すと確認メッセージが表示され、もう一度押すと飾りをすべて削除します。

## キー操作

| キー | 動作 |
|---|---|
| W / S | ツリーに近づく / 離れる |
| A / D | ツリーの周りを回転 |
| Delete（2回押す） | 1回目で確認メッセージを表示。もう一度押すとすべての飾りを削除 |
| L | 昼 / 夜を切り替える |
| P（押している間） | 印刷ボタンと印刷の案内を表示 |

カメラは設定された距離の範囲内で動きます。Pキーを押している間に表示される「印刷」ボタンを押すと、現在のツリーをA4縦で印刷できます。ブラウザーの印刷機能から印刷することもできます。印刷には日付が付きます。

## 保存データについて

保存データはブラウザー内に保存されます。別のブラウザーや端末とは共有されず、ブラウザーのサイトデータを消去すると保存データも削除されます。必要な配置を失わないよう、サイトデータを消去する前にご注意ください。

## 困ったときは

- **飾りが置けない**：葉の別の場所をクリックしてください。飾りが近くに集まりすぎている場合は、空きのある場所を選びます。
- **上限のメッセージが出る**：Deleteキーを2回押して、すべての飾りを削除してください。確認メッセージの後、もう一度押すと削除されます。
- **画面が表示されない**：WebGLとJSONモジュールの読み込みに対応するブラウザーを使用し、アプリをHTTPサーバー経由で開いてください。起動手順は[README](../README.md#起動方法)を参照してください。
