# 関数仕様書

## 対象と読み方

本書は `assets/` 内のアプリ独自JavaScriptについて、クラス、公開生成関数、名前付きの主要な内部関数を記述します。同梱の `assets/three/` は対象外です。パスは本書からの相対リンクです。値の型はJavaScriptの実行時型またはThree.jsの型を表します。戻り値の `void` は明示的な戻り値がないことを示します。

ファイル名は、モジュールがdefault exportするクラス名または生成関数名のkebab-caseとします（例: `DecorationController` → `decoration-controller.js`、`createSnowfall` → `snowfall.js`）。飾り生成器は `decorationFactories` のtypeキーをkebab-caseにした名前とし、export名とも一致させます（例: `candyCane` → `candy-cane.js`、`createCandyCane`）。設定JSONは `*-settings.json`、統合モジュールは `settings.js` です。同梱の `assets/three/` はこの規則の対象外です。

状態や設定の全体像は[内部設計・保守手順書](./内部設計・保守手順書.md)、操作仕様は[スタッフ向け詳細仕様書](./スタッフ向け詳細仕様書.md)を参照してください。

## 共通データ

| 名前 | 内容 |
|---|---|
| `settings` | `config/settings.js` が2つのJSONをトップレベルで結合した設定オブジェクト。値は各JSONを正本とする。 |
| `decorationFactories` | 飾りtypeを生成関数に対応付けるオブジェクト。HTMLの `data-decoration`、保存データのtypeと同じキーを使う。 |
| `state` | `{ saveCode, nextDecoration, decorations }`。各飾りは `{ type, size, color, position, quaternion, scale }` を持つ。 |
| `leaf` | `createChristmasTree()` が生成する葉の `THREE.Mesh`。`userData.coneRadius` と `coneHeight` を配置探索に使う。 |
| `decoration` | 飾りの `THREE.Group`。`userData.clearanceRadius` を衝突判定に使い、配置後はtype、size、colorも格納する。 |

`position` と `scale` は3要素、`quaternion` は4要素の数値配列です。飾りの変換はツリーのローカル座標系で保持します。

## 起動と設定

### [app.js](../assets/app.js)

トップレベルで飾り生成器を登録し、`AppView` → `SceneView` → `DecorationStore` → `DecorationModel` の順に生成します。3つのController（`DecorationController`、`SaveCodeController`、`SceneController`）の `start()` をこの順に実行した後、`SceneView.startAnimation()` を呼びます。外部に公開する関数はありません。

### [config/settings.js](../assets/config/settings.js)

2つのJSONモジュールを読み込み、`{ ...sceneSettings, ...appSettings }` をdefault exportします。同名トップレベルキーがあれば後者が丸ごと優先され、ネストした値は深く結合されません。

## Model

### [DecorationStore](../assets/models/decoration-store.js)

ブラウザーの `localStorage` に状態を格納します。ブラウザーのストレージ操作やJSON解析による例外は呼び出し元に伝播します。

| 関数 | 引数 | 戻り値 | 処理・副作用・例外 |
|---|---|---|---|
| `constructor(settings, decorationTypes)` | 設定、許可type文字列の配列 | インスタンス | typeを `Set` にし、状態キーの接頭辞とactiveキーを保持。 |
| `createCode()` | なし | `string` | 設定範囲の乱数を最大 `generationAttempts` 回試し、未使用番号を返す。見つからなければ `Error`。番号を予約・保存はしない。 |
| `save(state, code = createCode())` | 状態、任意の番号 | `string` | `saveCode` を番号で上書きしたJSONを番号別キーに書き、activeキーを更新。保存前の検証は行わない。2回の書き込みは原子的ではない。 |
| `loadActive()` | なし | `{ code, state }` または `null` | activeキーがなければ `null`。番号形式の確認後に `read` を呼ぶ。不正な番号や読み込み失敗は例外。 |
| `load(code)` | 番号 `string` | `state` | `read(code)` の結果を返す。 |
| `read(code)` | 番号 `string` | `state` | 番号別キーを読み、JSON解析・`validate`・データ内番号との一致確認を行う。未存在、不正JSON、不正状態、不一致は例外。 |
| `validate(state)` | 任意の値 | `void` | 所定のキー集合、番号、個数、飾りtype、数値・配列・色を検証する。不正時は `Error`。詳細は[保存仕様](./スタッフ向け詳細仕様書.md#4-保存仕様)。 |
| `isValidSaveCode(code)` | 任意の値 | `boolean` | 設定された桁数の半角数字文字列かを判定する。発行範囲内かどうかは確認しない。 |

`validate` 内のローカル関数 `hasExactKeys(value, keys)` は対象が非配列オブジェクトでキー集合が一致するかを、`validVector(value, length)` は配列の長さと各要素の有限性を判定します。いずれも `boolean` を返します。

### [DecorationModel](../assets/models/decoration-model.js)

飾りのオブジェクトとシリアライズ状態を管理します。保存失敗時の操作はトランザクションではなく、既に行った画面・メモリ上の変更は自動で巻き戻りません。

| 関数 | 引数 | 戻り値 | 処理・副作用・例外 |
|---|---|---|---|
| `constructor(settings, sceneView, decorationFactories, store)` | 設定、SceneView、生成器の辞書、Store | インスタンス | ツリー参照と依存先を保持し、飾り配列・次の通し番号・現在番号を初期化。 |
| `serialize(code = currentCode)` | 任意の番号 | `state` | 飾りのtype・size・colorとツリー内の位置・姿勢・スケールを配列化する。保存は行わない。 |
| `save(code = currentCode)` | 任意の番号 | `string` | 状態を `store.save` に渡し、成功時に現在番号を更新。番号が空ならStoreで発行。ストレージ例外は伝播。 |
| `loadActive()` | なし | 番号 `string` または `null` | active状態があれば `restore` 後に現在番号を設定。なければ `null`。読込・復元時の例外は伝播。 |
| `load(code)` | 番号 `string` | 番号 `string` | 検証済み状態を読み、復元して現在番号を更新。保存・activeキー更新はしない。例外は伝播。 |
| `restore(state)` | 検証済み状態 | `void` | 現在の飾りを破棄し、保存済みの種類・サイズ・色・変換から生成し直す。quaternionは正規化する。自分では状態検証しない。 |
| `add(type, leaf, hitLocal)` | 種類 `string`、葉Mesh、葉ローカルの `THREE.Vector3` | 保存番号 `string` | 個数上限を確認し、次のサイズ・色を選び生成、`findDecorationPosition` で位置探索してツリーに追加し保存。上限、不明type、配置不可、保存失敗等は例外。配置不可の仮飾りは破棄。 |
| `removeAll(newCode = false)` | 新番号発行の真偽値 | 保存番号 `string` | 新番号指定時は先に未使用番号を探す。飾りを破棄し通し番号を0にして、その番号または現在番号へ空状態を保存。 |
| `clearObjects()` | なし | `void` | 飾りをツリーから外し、`disposeDecoration` でリソースを解放して配列を空にする。保存や通し番号の更新はしない。 |

同ファイルの内部関数:

| 関数 | 引数と戻り値 | 処理 |
|---|---|---|
| `disposeDecoration(decoration)` | 飾り → `void` | 子MeshのGeometry・Materialを重複なく集めて `dispose()`。テクスチャの汎用的な破棄は行わない。 |

### [decoration-position.js](../assets/models/decoration-position.js)

配置探索の専用モジュールです。`assets/config/settings.js` を直接参照するため、設定は引数で受け取りません。

| 関数 | 引数と戻り値 | 処理 |
|---|---|---|
| `findDecorationPosition(decoration, leaf, hitLocal, decorations)`（default） | 飾り、葉Mesh、葉ローカルのヒット点、既存飾り配列 → `{ position, quaternion }` または `null` | クリック位置から高さ・角度の候補を探索し、ツリーローカルの位置・姿勢を返す。境界の法線方向投影と衝突距離を考慮し、見つからなければ `null`。 |

同ファイルの内部関数:

| 関数 | 引数と戻り値 | 処理 |
|---|---|---|
| `overlaps(decorations, position, clearanceRadius)` | 既存飾り配列、ツリーローカル位置、半径 → `boolean` | 既存飾りとの中心距離が両半径と設定gapの合計より小さいかを判定。 |
| `getSurfaceBounds(decoration)` | 飾り → 境界情報の配列 | 子MeshとInstancedMesh各インスタンスの境界箱から、中心と3本の半軸を算出。 |

### [decoration-orientation.js](../assets/models/decoration-orientation.js)

| 関数 | 引数と戻り値 | 処理 |
|---|---|---|
| `getDecorationOrientation(decoration, normal, coneAxis, placementSettings)`（default） | 飾り、法線、円錐軸、配置設定 → `THREE.Quaternion` | 通常は設定軸を法線に合わせる。靴下は履き口を円錐頂点側へ向け、`keepOutsideSurface` や `orientationOffset` も考慮。 |

## Controller

### [DecorationController](../assets/controllers/decoration-controller.js)

イベントハンドラーの戻り値はすべて `void` です。各イベントは `start()` で登録され、登録解除の仕組みはありません。保存番号の操作は `SaveCodeController` が担当します。

| 関数 | 引数 | 処理・副作用・例外 |
|---|---|---|
| `constructor(model, sceneView, appView)` | Model、SceneView、AppView | 依存先、Raycaster、選択初期typeを保持。 |
| `start()` | なし | 飾りメニュー選択・canvasクリック・canvasホイールのイベントを登録。 |
| `selectDecoration(event)` | クリックイベント | `data-decoration` のあるボタンを探し選択・状態表示。対象外なら何もしない。 |
| `selectDecorationButton(button)` | 飾りボタン | 選択中の種類を保持し、選択状態とステータス表示を更新する。`selectDecoration` と `cycleDecoration` の共通処理。 |
| `cycleDecoration(event)` | ホイールイベント | canvas上の転がり方向に応じて、ボタン一覧のDOM順序で選択中の飾りを円状に切り替える。入力欄・テキスト欄の上や縦の転がりがない場合は何もしない。canvas上では既定のスクロールを抑止する。 |
| `placeDecoration(event)` | canvasクリックイベント | レイを作り葉に交差した最初の点を葉ローカルへ変換し `model.add` を呼ぶ。成功時は番号更新・メッセージ消去、例外時はConsoleと状態表示。 |

### [SaveCodeController](../assets/controllers/save-code-controller.js)

イベントハンドラーの戻り値はすべて `void` です。保存状態の復元・読み込み・保存・初期化と、Deleteキーによる初期化の2段階確認を管理します。

| 関数 | 引数 | 処理・副作用・例外 |
|---|---|---|
| `constructor(model, appView)` | Model、AppView | 依存先と初期化の確認待ち状態を保持。 |
| `start()` | なし | active状態を復元し、フォーム・入力整形・初期化・キーイベントを登録。さらにcanvasのクリック・ホイールと飾りメニュー内の飾りボタンクリックに確認待ち解除を登録。 |
| `restoreSavedState()` | なし | `model.loadActive()` を呼び、成功時は番号表示。未保存または復元例外時は `save()` で現在状態を保存。復元例外はConsoleに記録。 |
| `loadByCode(event)` | submitイベント | 標準送信を抑止しフォーム検証後に `model.load`。成功時は番号表示・完了通知・メニュー閉鎖、失敗時はConsoleと状態表示。 |
| `reset()` | なし | 未使用番号を発行して `model.removeAll(true)` で飾りを空にし、新しい番号で保存。成功時は番号表示、確認待ち解除、メニューを閉じ入力欄を消去。失敗時はConsoleと状態表示。初期化ボタンとDeleteキーの確定操作から呼ばれる。 |
| `save()` | なし | Modelを保存して番号表示。失敗時はConsoleのみ。 |
| `handleKeyDown(event)` | キーイベント | Mは入力欄・テキスト欄では無視し、リピートを除いてメニュー開閉。Deleteは1回目に初期化の確認メッセージを表示し、もう一度押すと新番号での初期化（`reset`）を実行する。リピートは無視し、Delete以外のキー押下で確認待ちを解除する。入力欄でも確認つきで実行する。 |
| `requestReset()` | なし | 確認待ちでなければ確認メッセージを表示して待ち状態にし、待ち状態なら `reset`（未使用番号を発行して飾りを空に初期化）を実行する。 |
| `cancelResetConfirmation()` | なし | 初期化の確認待ちを解除する。他のキー押下、canvasのクリック・ホイール、飾りボタンの選択、`reset` 実行時に呼ばれる。 |

### [SceneController](../assets/controllers/scene-controller.js)

| 関数 | 引数・戻り値 | 処理・副作用 |
|---|---|---|
| `constructor(sceneView, appView)` | 2つのView → インスタンス | 依存先を保持し昼状態で初期化。 |
| `start()` | なし → `void` | キー、blur、resize、印刷ボタン、beforeprint、afterprintを登録。登録解除はない。 |
| `handleKeyDown(event)` | キーイベント → `void` | Lで昼夜切替（リピート無視）、Pで印刷ボタン等表示、W/S/A/Dでカメラ移動。入力欄フォーカスの判定はしない。 |
| `handleKeyUp(event)` | キーイベント → `void` | Pを離すと `hidePrintHint()`。 |
| `hidePrintHint()` | なし → `void` | 印刷ボタンと案内を隠す。blur時にも呼ばれる。 |
| `preparePrint()` | なし → `void` | 印刷用画像・日付のDOMを `scene.preparePrint` に渡す。 |
| `print()` | なし → `Promise<void>` | ボタンを無効化し画像生成・decode後に `window.print()`。失敗時は画面復元とConsole記録。最後にボタンを有効化。 |

## シーンオブジェクト生成関数

以下はView層の3D表現部品で、`views/scene/` 配下にあります。すべてdefault exportです。生成時に統合済み `settings` を参照します。`Group` や `Mesh` は `THREE` の型です。

| ファイル / 関数 | 引数 → 戻り値 | 処理・副作用 |
|---|---|---|
| [christmas-tree.js](../assets/views/scene/christmas-tree.js) `createChristmasTree()` | なし → `{ tree: Group, leaves: Mesh[] }` | 幹、円錐形の葉、頂上の星を生成。葉に半径・高さのuserDataを設定。 |
| [brick-floor.js](../assets/views/scene/brick-floor.js) `createBrickFloor(radius, topY)` | 半径、床上面Y → `Group` | 床の円盤と色別InstancedMeshのレンガを生成。レンガ色は乱数で選択。 |
| [floor-text.js](../assets/views/scene/floor-text.js) `createFloorText(text, centerRadius, color)` | 文字、配置半径、色 → `Mesh` | Canvas 2Dに縁付き文字を描き、床面上のテクスチャとして返す。 |
| [house.js](../assets/views/scene/house.js) `createHouse(groundY)` | 床面Y → `Group` | 設定に基づく家を生成し、床面高さを反映。 |
| [santa.js](../assets/views/scene/santa.js) `createSanta()` | なし → `Group` | サンタの各部品を生成。位置・全体スケールは呼び出し側で設定。 |
| [clock-tower.js](../assets/views/scene/clock-tower.js) `createClockTower(groundY)` | 床面Y → `{ group, updateTime }` | 時計塔を生成。`updateTime()` は現在時刻から時針・分針の回転を更新。 |
| [snowfall.js](../assets/views/scene/snowfall.js) `createSnowfall(scene, floorRadius, floorTopY)` | シーン、床半径、床面Y → 更新関数 | 雪粒子をシーンに追加。戻り値の `updateSnowfall()` は毎フレーム位置を進め、床や外周を越えた粒子を再配置。 |
| [floor-gift-boxes.js](../assets/views/scene/floor-gift-boxes.js) `createFloorGiftBoxes(floorTopY, house)` | 床面Y、家オブジェクト → `Group` | 家・葉・既配置箱・床境界を避けて床の箱を生成。後方の箱を規定回数内で配置できなければ `Error`。家前候補は不足しても例外にしない。箱の形状は [gift-box.js](../assets/views/scene/gift-box.js) が担当。 |
| [landscape.js](../assets/views/scene/landscape.js) `createLandscape(scene)` | シーン → `{ clockTower, updateSnowfall }` | 床・家・サンタ・時計塔・床ギフト・降雪を生成してシーンに追加し、常時更新する対象を返す。家と床ギフト・降雪はシーンへ直接追加される。 |

### 床ギフトと雪の内部関数

| ファイル | 関数 | 引数 → 戻り値 / 処理 |
|---|---|---|
| floor-gift-boxes.js | `randomBetween(minimum, maximum)` | 数値2つ → 数値。`minimum + random × (maximum - minimum)`。 |

## 飾り生成関数

各関数は飾りの `THREE.Group` を返し、`userData.clearanceRadius` を設定します。実際の位置・姿勢と保存用userDataの設定は `DecorationModel.add` / `restore` が担当します。引数 `size` は基準サイズ、`color` は色文字列です。

| type / ファイル | 関数 | 特記事項 |
|---|---|---|
| `ball` / [ball.js](../assets/views/scene/decorations/ball.js) | `createBall(size, color)` | 球と装飾を生成。 |
| `star` / [star.js](../assets/views/scene/decorations/star.js) | `createStar(size, color)` | 星形の飾りを生成。 |
| `snowflake` / [snowflake.js](../assets/views/scene/decorations/snowflake.js) | `createSnowflake(size, color)` | 雪の結晶を生成。色の選択はModelが専用配列から行う。 |
| `gift` / [gift.js](../assets/views/scene/decorations/gift.js) | `createGift(size, color)` | ツリー用の箱とリボンを生成。床ギフトとは別。 |
| `candyCane` / [candy-cane.js](../assets/views/scene/decorations/candy-cane.js) | `createCandyCane(size)` | 設定の曲線・縞色で生成。Modelからの第2引数は使用しない。 |
| `wreath` / [wreath.js](../assets/views/scene/decorations/wreath.js) | `createWreath(size, color)` | リースと装飾を生成。 |
| `bell` / [bell.js](../assets/views/scene/decorations/bell.js) | `createBell(size, color = settings.decorations.colors[0])` | 鐘を生成し、葉から外向きに保つための姿勢情報を設定。 |
| `stocking` / [stocking.js](../assets/views/scene/decorations/stocking.js) | `createStocking(size, color)` | 設定された輪郭を押し出して生成し、履き口を円錐頂点側に向ける姿勢情報を設定。履き口の部品は [stocking-cuff.js](../assets/views/scene/decorations/stocking-cuff.js) が担当。未対応の輪郭コマンドは `Error`。 |

### [stocking-cuff.js](../assets/views/scene/decorations/stocking-cuff.js)

靴下の履き口を担当するモジュールです。

| 関数 | 引数と戻り値 | 処理 |
|---|---|---|
| `createStockingCuff(colorIndex, thickness)`（default） | 色配列のインデックス、本体の厚み → `THREE.Group` | 設定の色から履き口・折り返し・縫い目の材質を選び、4枚の板と折り返し、縫い目をグループにまとめる。寸法は参照サイズ基準で、拡大は呼び出し側の `scale` が担当。 |
