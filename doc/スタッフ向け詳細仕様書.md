# クリスマスツリー スタッフ向け詳細仕様書

この文書は、リポジトリ直下の現行アプリの画面、操作、内部構成、保存形式を記述します。以下のファイルパスはリポジトリルートを基準とします。利用者向けの手順は[利用者向け説明書](./利用者向け説明書.md)を参照してください。

関数ごとの仕様は[関数仕様書](./関数仕様書.md)、イベントやデータの流れ、設定および確認手順は[内部設計・保守手順書](./内部設計・保守手順書.md)を参照してください。

## 1. 概要と実行環境

- HTML、CSS、JavaScript ES Modulesで構成する、ブラウザー内で動作するフロントエンドアプリです。
- 3D描画には同梱のThree.js r186を使用します。アプリ側のビルド工程や外部APIはありません。
- `assets/config/settings.js` が `scene-settings.json` と `app-settings.json` をJSON import attributesで読み込み、設定を統合します。
- `file://` からの直接起動ではなく、HTTPサーバー経由で配信してください。WebGLおよびJSON import attributesに対応するブラウザーが必要です。
- 状態は `localStorage` に保存されます。保存領域はブラウザーとオリジンに依存し、サーバー同期や端末間共有はありません。

ローカルでの起動例（リポジトリルートで実行）:

```powershell
python -m http.server 8000
```

その後 <http://localhost:8000/> を開きます。

## 2. ファイル構成と責務

役割はMVCに従い、`controllers/` が入力イベント、`models/` が状態・永続化・配置計算、`views/` がDOM表示と3D描画（`views/scene/` 配下の3Dオブジェクト生成器を含む）を担います。`assets/app.js` がこれらを組み立てて起動します（設定 `config/` は共通の参照元です）。

## 3. 画面と操作仕様

### 飾りの配置

- 飾りと保存データのtype値は `ball`、`star`、`snowflake`、`gift`、`candyCane`、`wreath`、`bell`、`stocking` です。初期選択はボールです。
- canvasのクリック位置をRaycasterで検査し、ツリーの葉との交差がある場合だけ配置します。葉以外へのクリックは無視します。
- 葉の表面上でクリック位置に近い候補を探索し（`assets/models/decoration-position.js`）、形状の外形と葉面の法線に合わせて向きを決めます（`assets/models/decoration-orientation.js`）。既存飾りとの間隔も検査し、配置場所が見つからない場合はエラーを画面表示します。
- 配置数の上限は全体50個、種類別20個です。サイズは設定配列を順に循環し、色は共通色配列から選択します（雪の結晶は専用配列）。
- canvas上のマウスホイール操作でも飾りを選択できます。飾りボタンのDOM順序に沿って選択中の種類を円状に切り替え、ホイールを下ろすと次の種類、上げると前の種類です。入力欄・テキスト欄の上では無視し、縦の転がりがない場合も選択は変えません。選択状態・表示・初期化の確認待ち解除はボタンによる選択と同じです。canvas上ではホイールによるスクロールを抑止します。
- Deleteキーの1回目の押下では初期化の確認メッセージを表示し、もう一度押すと未使用の保存番号を発行して、飾りのない状態をその番号に保存します。以前の番号のデータは削除しません。Deleteキーのリピートは無視します。Delete以外のキーの押下や、canvasのクリック・ホイール、飾りボタンの選択、初期化ボタンにより確認待ちは解除されます。入力欄でも同じ確認つきの初期化を実行します。
- 操作結果や配置エラーは右側のステータスに表示します。ステータスが空で保存番号メニューも閉じていると、パネルを隠します。

### 保存番号メニュー

- Mキーでメニューを開閉します。入力欄またはテキスト欄にフォーカスがある場合、Mによる開閉は行いません。メニューを開くと入力欄に現在の番号を入れ、入力欄へフォーカスします。
- 入力値から半角数字以外を除き、最大6文字に制限します。フォームでは6桁を必須とします。
- 「呼び出す」は番号に紐づくデータを復元し、現在の番号を切り替えます。呼び出しそのものでは書き込みません。以後の状態変更による保存時にactive番号が更新されます。
- 「初期化（新番号）」は未使用の番号を発行し、飾りのない状態をその番号に保存します。以前の番号のデータは削除しません。
- 起動時にactive番号がなければ、新しい番号を発行して空状態を保存します。保存番号の発行は設定回数内で未使用番号を探し、発行できない場合はエラーになります。
- 読み込み、初期化、削除の結果は画面に表示します。失敗時は該当イベントでConsoleにエラーを記録し、画面にも操作エラーを表示します。

### カメラ、昼夜、印刷

| 操作 | 挙動 |
|---|---|
| W / S | カメラをツリーへ近づける / 遠ざける。設定範囲に制限 |
| A / D | カメラを水平に5度ずつ回転 |
| L | 昼夜を切り替え。夜間時は「夜」ボタンと昼夜キー案内を表示 |
| P（押している間） | 印刷ボタンとPキー案内を一時表示。キーを離すかウィンドウがblurすると隠す |
| 印刷ボタン / ブラウザー印刷 | 印刷用画像を生成して印刷。印刷終了後に画面表示へ戻す |

印刷画像はcanvasからPNGデータURLとして生成し、1588×2246ピクセル（A4縦比率）です。印刷ページには日付、所属表示、保存番号を重ねます。印刷時は操作UIとWebGL canvasを隠します。印刷ボタンからの印刷は画像decode後に開始し、失敗時は画面カメラを復元してConsoleに記録します。

## 4. 保存仕様

### Local Storageキー

| キー | 用途 |
|---|---|
| `christmas-tree-decoration-state:<6桁番号>` | 保存番号ごとの状態JSON |
| `christmas-tree-active-decoration-state` | 次回起動時に復元する保存番号 |

状態変更時に現在番号のデータを保存し、active番号を更新します。番号の呼び出しは現在表示する状態と番号を切り替えますが、その時点では保存しません。新番号への初期化では旧番号を保持します。

### 保存データ形式

```json
{
  "saveCode": "123456",
  "nextDecoration": 0,
  "decorations": [
    {
      "type": "ball",
      "size": 0.18,
      "color": "#ff3333",
      "position": [0, 0, 0],
      "quaternion": [0, 0, 0, 1],
      "scale": [1, 1, 1]
    }
  ]
}
```

復元前に以下を検証します。

- 状態と飾りオブジェクトのキーが所定の集合に一致すること。
- 保存番号が6桁で、要求した番号とデータ内番号が一致すること。
- `nextDecoration` が0以上かつ全体上限以下の整数であること。
- 飾りtypeが登録済みで、全体数と種類別数が上限以内であること。
- サイズが正の有限数、色が `#RRGGBB`、positionとscaleが3要素、quaternionが4要素の有限数配列であること。
- scaleの各値が正数で、quaternionがゼロ長でないこと。

## 5. 主な設定値

設定ファイルが各値の正本です。設定を更新した場合は、関連する文書も合わせて更新してください。

| 項目 | 現行値 |
|---|---|
| 昼 / 夜の背景 | `lightcyan` / `steelblue` |
| 通常カメラ | 視野角75度、初期位置 `[0, 7.5, 11]`、注視点 `[0, 5, 0]` |
| 印刷カメラ | 視野角70度、位置 `[0, 5, 13]`、注視点 `[0, 3, 0]` |
| カメラ移動 | W/S 1回0.2、A/D 1回5度 |
| カメラ距離 | 最小＝最大葉半径＋2、最大＝床半径の1.8倍 |
| 飾り上限 | 全体50、種類別20 |
| 飾りサイズ | 0.18、0.22、0.26、0.20、0.24（循環） |
| 共通色 | `#ff3333`、`#ffd700`、`#3399ff`、`#ffffff`、`#ff66aa`、`#66dd88`、`#00ac9a`、`#eb6ea0` |
| 雪の結晶色 | `#87cefa`、`#ffffff`、`#b0e0e6`、`#dbeafe` |
| 保存番号 | 100000〜999999の6桁。発行時の探索は最大100回 |
| 床 | 半径12、上面Y=-2.005 |
| 葉 | 3段。半径 / 高さ / 中心Yは `[2 / 2 / 8]`、`[3 / 3 / 6]`、`[3.5 / 4 / 4]` |
| 印刷 | A4縦、画像1588×2246ピクセル |

配置探索の詳細、飾り形状、舞台オブジェクト、色や材質の値は `assets/config/app-settings.json`、`assets/config/scene-settings.json` および対応する `assets/views/scene/` モジュールを参照してください。

## 6. 保守時の注意

- 利用者向けのREADMEと利用者向け説明書では、保存番号の表示・呼び出し・発行のしくみを説明しない方針とする。Mキーのメニューは内部機能・スタッフ向けとして扱い、利用者向けの文書は自動保存についてだけ記述する。メッセージや操作説明を変更するときは、利用者向けの表示から「保存番号」という語が出ないようにする。
- 飾りを追加・変更するときは、`assets/app.js` のimportと `decorationFactories`、`index.html` の `data-decoration` ボタン、保存データ検証に使う種類一覧を連動させます。type値の変更は既存保存データとの互換性に影響します。
- DOM要素を追加・変更するときは、`AppView` の参照と関連Controller、表示状態の連動を確認します。
- 設定値や操作を変更した場合は、README、利用者向け説明書、関連する本仕様書の記載を同期します。
- 飾りの生成・失敗・削除・復元では、専用GeometryとMaterialのライフサイクルを保ちます。配置失敗の仮飾りや削除対象のリソースを破棄する処理を確認してください。
